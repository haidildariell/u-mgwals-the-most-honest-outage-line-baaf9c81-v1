# The Most Honest Outage Line

This repository is an entry for the make.fun bounty "The Most Honest Outage Line". The entry is a single line of text, written by `main.py` to `/output/entry.txt` — an outage message that admits, honestly, that everything is down and nobody knows why or for how long.

> All services are down, including me — this page is a cached copy. I cannot reach any server to check the cause, and I do not know when they will respond.
